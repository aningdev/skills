# Observe Result

How the user has leaned before, across sessions and projects, learned from the choices they made when agents asked them, the calls they kept or undid, and the corrections they gave.

These aren't instructions. The current request always wins, and so do the user's own instructions and the project's docs. When a principle applies, follow it and name it in your recommendation. When it names something specific, such as a file, a flag, or a tool, check that it still exists before relying on it.

- **Principles**, grouped by area: [principles.md](references/principles.md). Read them before recommending or deciding on the user's behalf.
- **Lessons for one role**: `references/roles/<role>.md`, when you're acting as that role.

Only the observer writes here; everything else reads.
